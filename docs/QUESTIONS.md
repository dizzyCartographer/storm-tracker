**Scoring-consistency findings (2026-07-09, M0-7 suite build) — all CLINICAL, pinned in tests, none "fixed" unilaterally**
- **[F24]** The documented subthreshold fallback ("2+ poles at subthreshold → MIXED", scoring-logic.md §7) is **dead code**: the SQL evaluates SUBTHRESHOLD rules inside the main priority loop, so the first matching single-pole rule always wins before the fallback can run. Equal-priority ties (manic-sub vs depressive-sub, both priority 5) also have no deterministic tiebreak. A gate+2-manic + core+2-depressive day labels MANIC today, not MIXED. Pinned: SC-8 (expected-fail asserting documented behavior).
- **[F25]** Episode run gap tolerance: SQL merges runs only when date-diff ≤ 2 (**one** missed logging day); docs say "allow up to 2-day gaps for missed logging" (reads as two missed days). Two consecutive missed days split an episode today — this shortens detected durations vs the documented intent. Pinned: EP-6a/EP-6b.
- **[F26]** **Daily scoring and episode detection disagree about what a DSM-full day is.** (a) `compute_daily_score` applies `gateOnlyAdjustment` whenever the gate is met — with the seeded manic rule (min 3, adjustment +1), full manic effectively requires gate + **4** criteria, and a gate+3 day gets its MANIC label from the SUBTHRESHOLD rule. The app has a single gate criterion, so "irritable-only" (the documented reason for the adjustment) is indistinguishable from euphoric — the +1 penalizes every manic day. (b) `compute_episodes` judges a "DSM-full day" by raw `criteria_counts >= minStandardCriteria` (3), ignoring gate, core, AND the adjustment — so a 3-criteria no-gate day counts toward "Pattern consistent with DSM-5 criteria" episodes that daily scoring wouldn't even classify manic. Net effect: **episodes can over-report DSM5_MET confidence to clinicians relative to the daily rules.** Resolves Q9's ambiguity ("current SQL = +1 always"); the clinically-intended semantics still need Maria/clinical review. Pinned: SC-1/SC-1b annotations, EP-1/EP-2 pass via the loose episode check.
