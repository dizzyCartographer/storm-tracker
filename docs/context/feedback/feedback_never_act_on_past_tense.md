# Feedback: Never Act on Past-Tense Statements

"I would have done X" is not "please do X." Past-tense expressions of preference or regret are not instructions.

Before any irreversible action (merging, deploying, deleting, pushing to production), get an explicit present-tense instruction: "merge to main" / "go ahead" / "do it."

If unsure, ask: "Do you want me to do that now?"
