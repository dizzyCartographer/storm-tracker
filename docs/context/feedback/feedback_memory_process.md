---
name: Memory writing process
description: Always show memory content to user for approval before writing. Write to both memory folder and docs/context/.
type: feedback
---

Never write a memory file without showing the content to the user first and getting explicit approval. Once approved, write to both the memory folder and `docs/context/`.

**Why:** A memory was written mid-debugging that captured a problem but not its resolution, creating a contradictory record that caused confusion and wasted time.

**How to apply:** Show the exact memory content to the user. Wait for explicit approval. Then write to both locations.
