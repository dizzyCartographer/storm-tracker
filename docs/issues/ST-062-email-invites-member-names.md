Two changes to the invite system:

1. **Email-based invites.** Create invite links associated with a specific email address so the invite can only be accepted by the intended recipient.

2. **Member name display.** When an invite is accepted, show the member's actual name in the project member list instead of just "Member (Caregiver)". Currently there's no way to see who joined — just their role.

Both web and mobile need these changes.
